# TransitCare - Style Guide

** This style guide is to provide a consistent look and feel for the project which reflects the Winnipeg Transit brand. It is intended to be used by developers, designers, and content creators working on the TransitCare project. **

## Colour Pallette

Three main colours:
#003055 - Dark Blue
#f0a400 - Yellow/orange for highlighting
#e9ecef - Light grey for backgrounds and borders

Font family: Arial, sans-serif
H1: 36px, bold
H2: 30px, bold
H3: 24px, bold
Body: 16px, regular
