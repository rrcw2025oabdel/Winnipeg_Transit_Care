# TransitCare - Style Guide

** This style guide is to provide a consistent look and feel for the project which reflects the Winnipeg Transit brand. It is intended to be used by developers, designers, and content creators working on the TransitCare project. **

## Colour Pallette

Three main colours:
Primary: #003055 - Dark Blue
Secondary: #f0a400 - Yellow/orange for highlighting/accents
Tertiary: #e9ecef - Light grey for backgrounds



Extended colour palette:

# Colour usage rules
- Use tokens instead hex codes for colours in CSS and design tools. Will provide a consistent colour palette across the project and make it easier to update colours in the future.
- Please ensure sufficient contrast between text and background colours for accessibility. Eg: Avoid white on gold



# Font usage rules
- Use tokens instead of hardcoding font values in CSS and design tools. This ensures consistency and makes it easier to update fonts in the future
-Do not use more than 2 font families in the project. Use one for headings and one for body text. This will help maintain a clean and professional look.
-Do not go below 16px for body text. This ensures readability and accessibility for all users. Anything 12px should be used for captions or small print only.

Font family: Arial, sans-serif
H1: 36px, bold
H2: 30px, bold
H3: 24px, bold
Body: 16px, regular
